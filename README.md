# Portfolio de Carolina Granda

Portfolio profesional, bilingüe y responsive de **Carolina Granda**, Client Support & Events Coordinator. La web presenta experiencia real en coordinación, atención al cliente, hospitality y operaciones internacionales, junto con una selección de proyectos creativos.

## Tecnología

- HTML5 semántico
- CSS3 responsive
- JavaScript sin dependencias
- Formulario compatible con Netlify Forms y fallback a correo
- Selector EN/ES con preferencia guardada localmente

No necesita instalación ni proceso de compilación. Se puede abrir directamente con `index.html` o servir como web estática.

## Estructura

```text
PortfolioWeb/
├── index.html
├── css/styles.css
├── js/
│   ├── main.js
│   └── portfolio.js
├── assets/
│   ├── documents/carolina-granda-cv.pdf
│   ├── icons/favicon.svg
│   └── images/
└── disenos_proyectos/
```

Los textos bilingües, datos de proyectos e interacciones están en `js/portfolio.js`. Las piezas completas del portfolio se conservan en `disenos_proyectos/` y sus portadas optimizadas para la web están en `assets/images/`.

## Contenido incluido

- Perfil, experiencia y formación extraídos del CV de Carolina.
- Experiencia freelance, internacional, educativa y de hospitality.
- Propuesta de viaje y evento de Portimão.
- Invitaciones personalizadas para celebraciones familiares.
- Diseño de despedida de soltera.
- Colección infantil bilingüe Christmas Animals.
- Identidad y enlace social de Díselo con diseños.
- Contacto completo con teléfono de Reino Unido y España, LinkedIn e Instagram.

## Formulario

En un dominio `*.netlify.app`, el formulario utiliza Netlify Forms. En local, GitHub Pages u otro alojamiento estático abre el cliente de correo con el mensaje preparado para `carolinaceeg@gmail.com`.

## Publicación

La web es compatible con GitHub Pages, Netlify y cualquier servidor estático. No hay comando de build; la carpeta raíz es el directorio de publicación.
